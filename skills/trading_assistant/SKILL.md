# 交易助手技能（专家系统入口）
- 触发词：让专家看看、单专家模式、多专家模式、专家会诊、图形买点体系怎么看、方向仓位体系怎么看、图形买点体系分析、综合专家意见
- 功能：可插拔专家系统，支持单专家 / 多专家商量两种模式
- 专家来源：utils/experts/ 目录自动发现，新增专家只需加一个 .py 文件 + 规则 md

## 模式一：单专家模式
触发：用户指定专家（如"用图形买点体系分析XXX"）
流程：
1. 运行 `python3 skills/trading_assistant/main.py list` 确认专家存在
2. 运行 `python3 skills/trading_assistant/main.py prompt <专家名>` 获取该专家完整规则提示词
3. 结合行情数据（大盘复盘/个股分析技能拉取），严格按该专家规则输出分析
4. 规则与行情冲突时以规则为准

## 模式二：多专家商量模式（默认）
触发：用户说"让专家们看看"、"专家会诊"、"多专家"或未指定专家
流程：
1. 运行 `python3 skills/trading_assistant/main.py list` 获取全部可用专家
2. 对每个专家，用 delegate_task 并行派发子代理分析，每个子代理的 goal 包含：
   - 该专家完整规则（先运行 main.py prompt <专家名> 获取）
   - 同一份行情数据（JSON格式传入）
   - 要求：严格按该专家体系输出【结论】【理由】【操作建议】【风险提示】
3. 收集所有专家意见后，扮演"理性裁判"角色综合总结，输出：
   - 【共识】所有专家一致的观点（最值得信任）
   - 【分歧】专家们意见不同的地方及各自理由
   - 【裁判结论】基于用户画像（data/trader_profile.md）和当前风险偏好的最终建议
   - 【操作预案】明日/下一步具体操作计划
4. 裁判结论要独立于各专家，不被任何单一专家带偏；参考 trader_profile.md 中用户偏好

## 模式三：组合调用
- 大盘复盘 + 专家系统：先出大盘数据，再让专家基于数据给次日策略
- 个股分析 + 专家系统：先拉个股数据，再让专家给买卖点
- 操作复盘 + 专家系统：用户描述今日操作，专家体系评估执行质量

## 注意事项
- 行情数据用 utils/stock_data.py 的接口拉取（有当日缓存，勿重复请求）
- 报告风格：符号（▸▲▼★）+ 分隔线 + 框线，精炼如券商研报
- 专家规则文件在 utils/experts/*_rules.md，新增专家即加文件
- 每次重要分析后，如发现用户交易模式规律，更新 data/trader_profile.md
