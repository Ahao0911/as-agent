# 盘前提示技能（pre_market_brief）
- 触发词：盘前提示、今日盘前、开盘前怎么看、今天怎么做、简单盘前、深度盘前
- 功能：生成A股交易日盘前提示——当天交易计划卡（不是晨报），回答六个问题：今天适不适合交易？仓位多少？最可能情景？哪些板块/股票值得观察？什么条件出现才买？什么情况必须放弃或减仓？
- 闭环位置：读取昨日盘后推演 → 生成今日计划 → 保存（盘后复盘读取本报告做"盘前计划验证"）

## 启动流程
1. 读取昨日盘后推演（utils/forecast_store.py 自动加载最近 post_market 预测）
2. 构建盘前快照（utils/pre_market_flow.py 内部处理：复用当日缓存快照 + 汇率/商品/活跃市值补充）
3. 检查持仓、自选和候选池（读取 data/watchlist.json）
4. 生成三种盘中情景（基准/强势/弱势，概率总和100%）
5. 输出仓位、触发条件、禁止事项
6. 保存报告（data/reports/YYYY-MM-DD_pre_market.md + .json）+ 预测落盘
7. 默认不推送！只有用户明确说「推送」才推送

## 报告结构（标准模式，按序输出）
1. 一句话计划（市场基调+仓位+最重要交易条件）
2. 盘前风险等级（低/中/较高/高 + 仓位区间 + 是否进攻/搬砖/等待确认；仓位必须与活跃市值和黄白线状态关联）
3. 隔夜市场摘要（美股/韩股/汇率/商品/隔夜要闻——只保留会影响A股的，去重聚类说明传导方向，每项带截止时间）
4. 三种盘中情景（每项：概率/核心依据/触发条件/失效条件/对应仓位/交易策略）
5. 开盘后观察清单（3-5项：黄白线/成交额/市场宽度/主线/高位股反馈，每项注明确认/否定/仓位影响）
6. 持仓复查（逐只：现价/趋势/量能/偏离/止损/建议——个股读黄白线+砖型，ETF读均线20/60+量能，禁止无条件买卖指令）
7. 今日候选观察池（A级=条件接近完成/B级=需确认/C级=仅观察；个股未满足黄白线硬前提/ETF未满足均线多头硬前提不得列入A级）
8. 今日禁止事项（基于行为观察统计，最多3条可执行条款）
9. 今日执行卡（总仓位/首要观察/允许交易条件/必须减仓条件/最大风险/避免的错误）

## 报告模式
- 简单盘前：一句话计划 + 风险等级 + 仓位建议 + 三个观察指标 + 三情景 + 禁止事项（跳过逐票分析，最快）
- 标准盘前：完整结构（默认）
- 深度盘前：标准 + 持仓逐只分析 + 候选池分析 + 海外传导路径 + 新闻影响链 + 昨日预测对比

## 数据截止原则（铁律）
- 只能使用报告生成时间之前已公开的数据
- 韩股在A股开盘前已交易，可用生成时已发生的数据；美股用上一交易日
- 所有关键数据标注来源和截止时间
- 数据缺失明确说明，禁止编造
- 普通行情读缓存；全市场批量用MooTdx；持仓/自选用腾讯（限速1.2s+熔断30min）；iFinD仅财务/估值/新闻等受控用途，不消耗iFinD额度拉普通K线
- 单次任务中相同数据只能请求一次

## 表达规则
- 条件式表达：若……则…… / 只有……才…… / 当……失效时……
- 禁止：今天一定上涨 / 必然涨停 / 可以重仓稳赚 / 无风险机会
- 证据不足时明确说明证据不足

## 关键命令
- python3 utils/pre_market_flow.py                 # 标准盘前
- python3 utils/pre_market_flow.py --mode simple   # 简单盘前
- python3 utils/pre_market_flow.py --mode deep     # 深度盘前
- python3 utils/pre_market_flow.py --date 2026-08-03  # 指定交易日
- python3 utils/forecast_store.py stats            # 预测校准统计（方向命中率）

## 推送规则（生成与推送解耦）
- 默认 auto_push=false，只保存不推送
- 只有用户明确说「推送到钉钉」才推送
- 「推送上一份盘前提示」= 发缓存报告，不重新生成（utils/report_store.py load --type pre_market）

## ⚠ 指标使用边界（强制，2026-08-01确认 + 08-02 ETF改版）
- 大盘环境：只用活跃市值定仓位；指数均线/涨跌家数/成交额辅助；不用BBI黄白线/砖型图做开仓否决
- 板块：只用均线系统(20/60日)+量能+相对强弱；禁止板块砖型图/板块BBI
- 交易标的：个股=BBI黄白线(空头禁开仓铁律)+砖型图+单针下20；**ETF【2026-08-02改版】不用黄白线+红绿砖，只用均线MA20/MA60+量能**（图形买点体系不适用ETF）
- 研判流程：大盘活跃市值 → 板块均线 → 个股BBI+砖型图 / ETF均线+量能

## ⚠ 数据标注规范
- 区分【盘面定性结论(可靠)】和【价格/偏离%/止损位(推演估算)】
- 持仓成本/现价以用户提供为准，禁止用模板数值冒充
- 禁止自动生成脱离当前市价的止损价——止损优先人工输入
