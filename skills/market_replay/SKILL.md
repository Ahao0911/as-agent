# 大盘复盘技能
- 触发词：大盘复盘、收盘复盘、今日市场解读、全市场复盘、大盘分析
- 功能：拉取当日A股全市场行情数据，生成结构化的收盘复盘报告
- 输出格式：严格按照「大盘数据、板块轮动全景、全天三阶段节奏、多维度分析、次日方向预判」五大模块输出
- 适用场景：每日收盘后做市场整体复盘

## 完整工作流（每日复盘 + 黄白线选股）
复盘不仅看大盘，还要产出次日"可做池"。流程：

1. 大盘择时：`python3 utils/daily_flow.py`（或先跑本技能生成复盘报告）
2. 主线板块：从概念板块涨幅榜取 TOP5（成交额>500亿），记录每板块领涨股
3. 黄白线过滤（必要条件）：候选股逐只算白线(EMA(EMA(C,10),10)) / 黄线(BBI 14/28/57/114)
   - ★ 白线在黄线之上 = 多头区间 → 进入可做池
   - ✗ 白线在黄线之下 = 空头区间 → 过滤掉，不做
4. 输出可做池：按偏离黄线%排序，附 J 值、收盘/白线/黄线数值

完整命令：`python3 utils/daily_flow.py --top 5`
自定义候选池：`python3 utils/daily_flow.py --pool 600519 000858`（跳过板块选股，直接黄白线过滤）
单票分析：`python3 utils/test_pattern_indicator.py <代码>`
