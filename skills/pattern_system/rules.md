# 图形买点体系A股交易体系核心规则
## 一、大盘判断规则
1. 科创50是行情风向标，科创50站稳2150点以上，科技主线成立，可重仓参与
2. 沪深两市成交额低于2万亿为缩量，2.5万亿以上为天量，天量次日不追高，大概率分化
3. 大盘站上MA5、MA10均线为短期趋势向上，跌破MA30止损离场
4. 风格切换信号：资金从银行、红利、消费流出，流入科技、半导体时，果断切换进攻方向

## 二、仓位管理规则
1. 趋势明确时最高仓位8成，永远保留2成现金
2. 天量行情次日仓位降到5成，规避回调
3. 单只个股仓位不超过总资金2成
4. 亏损标的严格止损，单只亏损超5%无条件止损

## 三、买卖点规则
1. 买入：板块放量突破平台，个股回踩关键均线时低吸
2. 卖出：天量冲高回落、跌破5日线、短期涨幅超20%时止盈
3. 不追高开仓，尤其是早盘高开3%以上的标的不追
4. 止损位：买入价下方3-5%，破位坚决走

## 四、板块优先级
1. 主线：半导体、AI、通信、科创50
2. 次线：券商、机器人、计算机
3. 回避：银行、煤炭、红利等防御性板块在科技行情期不碰
