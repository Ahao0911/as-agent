# 图形买点体系：换手率指标（辅助过滤器·最后一关）

## 核心原则
- 不要死记固定百分比！优先和个股自身历史对比（相对换手），其次参考绝对值
- 换手率是辅助过滤器，不能单独作为买卖信号，配合黄白线/单针下20/砖型图使用
- 口诀：上涨锁仓看缩量；良性洗盘看缩量；高位警惕持续暴量
- 铁律：缩量回调=洗盘；放量下跌=出货

## 基础档位（中小盘 流通市值50~300亿）
| 换手率 | 含义 |
|---|---|
| <3% | 低换手冷清（横盘冷门/主力锁仓拉升） |
| 3%~7% | 温和健康（黄金区间，B1启动/B2突破最理想） |
| 7%~15% | 高换手分歧加大（连续多天需小心） |
| >15% | 超高换手（低位暴力吸筹 / 高位出货风险区） |

大盘权重股标准整体下调一档，2%以上即放量。

## 结合行情阶段用法
- B1底部：回调期换手持续走低（缩量）；拐点启动时温和放大3~7%，不直接爆量>12%；底部反弹单日>15%容易一日游
- B2调整加仓（最常用）：洗盘必须缩量，换手明显小于拉升阶段=良性洗盘；完美搭配单针下20+回调缩量换手
- B3主升加速：真正强势牛股越涨换手越低（锁仓）；进入B3后换手持续创新高=主力派发，准备S1减仓
- S1一卖：短期大涨后连续多天>12%高换手+股价滞涨；或股价创新高+换手同步天量 → 减仓
- S2/S3离场：高位下跌放量、反弹缩量；下跌当天换手放大=主力出货

## 洗盘VS出货（高频考点）
- ✅良性洗盘：上涨趋势站黄线上；回调缩量下跌换手逐步变小；单针下20出现、红线守住60
- ❌出货：股价高位；下跌放量换手居高不下；反弹缩量力度弱；后续大概率破黄白线

## 组合复盘流程
1. 黄白线 → 大趋势能不能做
2. 单针下20 → 回调位置是否到位
3. 砖型图 → 动量拐点确认
4. 换手率过滤器（最后一关）→ 回调缩量加分 / 回调放量直接放弃

## 三大误区
1. 机械套用固定数字：小盘10%正常、千亿大盘5%就是巨量，要对比该股近20日均换手（相对换手）
2. 只看单日换手：要看连续3~5天趋势
3. 把高换手当利好：低位放量是机会，高位放量是风险，位置优先于数值

## 极简口诀
- B1启动：温和放量3~7%最佳，拒绝爆量
- B2洗盘：回调缩量换手降低=良性
- B3主升：越涨换手越低=锁仓大牛
- S1卖点：大涨后持续高换手、滞涨，开始减仓
- 铁律：缩量回调=洗盘；放量下跌=出货
