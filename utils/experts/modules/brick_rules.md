# 图形买点体系配套副图：知行砖型图（玩超短）
> ✅ 2026-09-10 与知识库《砖型图.txt》原文逐行核对一致（指标公式 7 行为硬事实，无差异）。
> 《砖型图.txt》原文：`砖型图:=IF(VAR6A>4,VAR6A-4,0),COLORRED;`，与下方定义完全一致。

## 指标定义（通达信副图，无参数）
VAR1A=(HHV(HIGH,4)-CLOSE)/(HHV(HIGH,4)-LLV(LOW,4))*100-90
VAR2A=SMA(VAR1A,4,1)+100
VAR3A=(CLOSE-LLV(LOW,4))/(HHV(HIGH,4)-LLV(LOW,4))*100
VAR4A=SMA(VAR3A,6,1)
VAR5A=SMA(VAR4A,6,1)+100
VAR6A=VAR5A-VAR2A
砖型图=IF(VAR6A>4,VAR6A-4,0)
- 红柱：当前值>前一根 → 多头动量增强
- 绿柱：当前值<前一根 → 空头动量增强
- 本质：4K超短线动量指标，跟踪力量变化，不是看价格高低

## 核心规则（图形买点体系原版）
### 1. 前置大前提（最重要）
- 砖型图禁止单独使用！必须先用黄白线过滤大趋势
- ✅ 白线>黄线（多头环境）信号有效
- ❌ 白线<黄线（空头环境）红砖大多是反弹诱多，禁止重仓

### 2. 绿翻强红（核心买点形态）
- 标准定义：一段连续绿柱调整后，第一根新生红砖高度 ≥ 前段绿柱最大高度的 3/4
- 底层逻辑：连续绿柱=空头持续释放；绿翻强红=多头一次性集中承接，动量反转力度极强
- 对比：普通绿翻红（红砖很短）→ 弱反弹，只做极短线，不重仓
- 最优场景：B2 调整末端；共振加分：叠加单针下20低位买点
- 避雷：空头趋势下绿翻强红 = 诱多反弹，快进快出

### 3. 短柱长红（趋势延续）
- 短绿接长红（1-2根短绿洗盘后长高红砖）= 洗盘极短抛压小，多头主控，可持仓/加仓
- 红砖逐级走高 = 健康动量结构，安心持有
- 危险：长红后红砖一根比一根短 → 动能衰竭，随时红翻绿，提前减仓

### 4. 连续4块红砖减仓纪律（持仓止盈）
- 同一轮上涨波段内连续走出4根红砖 → 主动减仓30-50%锁定利润
- 误区：不是4砖清仓！强势主升常走5-6砖，防止卖飞
- 减仓后：继续创新高长红砖→剩余持有；红砖缩短/翻绿→全部离场

### 5. 其它高频形态
- 阶梯红砖：红柱高低交替震荡抬升 → 趋势稳健，适合波段持有
- 尖顶超长红砖：单根异常超长后迅速缩短/翻绿 → 短期见顶概率高
- 锯齿砖：红绿频繁来回切换 → 震荡行情，减少交易，容易反复止损

### 6. 次日开盘执行SOP（B1尾盘入场的隔夜决断，2026-08-03 项目主理人确认补全）
- 适用：前一日尾盘 B1 入场，次日早盘短线决断
- **9:33 / 9:37 两个观察节点**（连续竞价前几分钟资金试盘窗口；是观察窗口不是精确挂单点，看资金持续性）
- 分支① 拉不起来（走弱/低开低走/反弹无力）→ **直接全部清仓拍掉，不格局**
  - 底层逻辑：砖型图多头信号隔夜失效，资金没有承接，预期破坏，不要扛单
- 分支② 顺利拉升（多头承接有力）→ **先减 50% 底仓锁利**
  - 剩余 50% 防守方案1（短线）：移动止损上移到成本线/今日开盘价，跌回全部离场
  - 剩余 50% 防守方案2（波段）：持有冲击前高第一目标位；到前高滞涨/长上影/放量震荡→全部止盈；放量突破前高→继续持有抬高止损
- **当天砖型图转绿（红翻绿）→ 也走**（隔夜/当日动量失效，落袋防回调）

## B1/B2/B3 波段联动（核心战法）
波段定义：B1=第一启动浪（底部反转第一段上涨）、B2=调整浪（B1后回调洗盘）、B3=第二主升浪（爆发力最强）

- B1阶段：白线刚上穿黄线，出现绿翻强红=B1启动观察点；B1连红4砖减仓；仓位不宜过重（试错建仓）
- B2阶段（全场最佳买点区间，重中之重）：
  1. 白线持续站上黄线（中期多头未破坏）
  2. K线回调，砖型图连续绿柱释放空头动能
  3. B2末端出现绿翻强红 = B3启动核心信号
  4. 共振：同时触发单针下20低位买点
  → B2末端绿翻强红是整套体系盈亏比最高的机会，适合加大仓位布局B3
- B3阶段：绿翻强红开启新红砖序列；途中持续长红砖→安心持有；连续4红砖→第一次减仓；红砖缩短或红翻绿→分批清仓
- B3结束后不主观预判B4，耐心等新一轮B1-B2循环

## 高频坑点
1. 震荡行情B2结构不清晰、砖型图反复红绿切换 → 放弃操作
2. 空头趋势下绿翻强红一律当反弹，不重仓
3. 不要孤立看砖型图：大趋势（黄白线）> 波段结构（B1B2B3）> 砖型动量信号
4. 砖型图是右侧动量指标，只能跟踪力量变化，无法提前预测拐点，必须配套止损
