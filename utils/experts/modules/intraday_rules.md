# 盘中分时分析规范（图形买点体系 · 2026-08-03 项目主理人确认）

> 目的：盘中（交易时段）分析和盘后复盘用**不同指标组合**，避免盘中滥用日线指标。
> 项目主理人原话：分时图这样分析挺好的；红绿砖一般上午或下午的尾盘看（除非关键词"尾盘"或根据时间判断已到尾盘）；B1/单针感觉复盘再分析。

## 一、盘中分析用什么（交易时段 9:30-15:00）

### 1. 分时走势（核心，必看）
- 今开 vs 昨收（高开/低开/平开，幅度）
- 日内高低点：冲高回落 / 低开高走 / 横盘震荡
- 上影线/下影线含义：冲高回落=上方抛压；低开高走=资金承接
- 当前价在日内均价线上方还是下方（强弱分界）

### 2. 换手率（必看）
- 档位：<3冷清 / 3-7温和黄金 / 7-15高换手分歧 / >15超高不做
- ⚠ 盘中换手率是"半日/当前"值，要按时间折算：半天约×2、尾盘接近全天
- 相对自身20日均换手判断放量/缩量

### 3. 量比（必看，腾讯接口字段[49]）
- 量比 = 当前每分钟均量 / 过去5日每分钟均量
- <0.8 缩量 / 0.8-1.5 平量 / 1.5-3 放量 / >3 显著放量
- 结合价格：放量上涨=健康；放量滞涨/冲高回落=抛压；缩量回调=洗盘

### 4. 红绿砖（**上午尾盘 或 下午尾盘 或 用户提到"尾盘"时看**）
- ⚠ 红绿砖（砖型图）是日线级别信号，盘中早/中段看没有意义（当日K线未定型）
- 触发条件：a) 用户说"尾盘" / b) 当前时间 ≥ 14:30（下午尾盘，日K接近定型） / c) **上午尾盘 11:15-11:30**（上午收盘前，半日K线可参考当日动量倾向）
- 尾盘看什么：绿翻强红（明日动量）/ 红砖缩短（衰竭）/ 红翻绿（止盈信号）
- 上午尾盘看红绿砖的意义：判断午后方向倾向（上午已收阳/收阴，砖型红绿状态预示下午延续或反转）

### 5. 外盘风向（必看）
- 韩国KOSPI实时（znb_KOSPI，9:00开盘比A股早）—— 科技股风向标
- 富时A50（hf_CHA50CFD）—— A股先行指标
- 大盘指数实时（上证/创业板）

## 二、盘中不做什么

### ❌ 不分析（留给盘后复盘）
- **B1/B2/B3 节点**：需日线结构确认，盘中判断易失真 → 复盘再分析
- **单针下20**：日线信号，盘中无意义 → 复盘再分析
- **黄白线金叉死叉**：日线级别，盘中波动会误导 → 参考日线最新值即可
- **砖型图**（除非尾盘）：同上

## 三、盘中分析的输出结构

```
【分时】今开X（±Y%）→ 最高Z → 现价W（±V%）：冲高回落/低开高走/横盘
【换手】当前X%（半日，全天约2X%），相对20日均放量/缩量
【量比】X.X（放量/平量/缩量），结合价格：健康/抛压/洗盘
【外盘】KOSPI ±X% / A股指数 ±X%
【结论】持有/减仓/止损 + 关键价位（支撑/压力/止损线）
```

## 五、诊股票 / 复盘 = 完整图形买点体系（2026-08-03 项目主理人确认）

> 项目主理人原话："诊股票和复盘的时候记得全部的图形买点体系"

**只要不是盘中分时急问，诊股票和复盘必须输出完整图形买点体系**，缺一不可：
1. **黄白线**（主图定方向）：白线>黄线=多头区间（唯一硬前提），偏离黄线%
2. **砖型图**（副图找动量）：绿翻强红/红砖缩短/红翻绿/锯齿砖
3. **单针下20**（副图找位置）：白线下20/四线归零/白穿红线/白穿黄线
4. **B1/B2/B3节点**（买卖点骨架）：B1超跌/B2突破/B3主升 + 红肥绿瘦
5. **换手率**（过滤器）：档位(3-7黄金/7-15分歧/>15不做) + 相对20日均 + 洗盘VS出货
6. **量比**（盘中补充）：放量/缩量结合价格
7. **外盘风向**：KOSPI/美股/A50（影响当日情绪）

输出结构（诊股票/复盘标准模板）：
```
【趋势】黄白线：白X>黄X 多头✓｜偏离黄线Y%
【动量】砖型：绿翻强红/红柱↑（等翻红/衰竭）
【位置】单针：白线下20/四线归零/高位
【节点】B1/B2/B3 + 红肥绿瘦判断
【换手】X%（档位），相对20日均放/缩量，洗盘or出货
【量比】X.X（盘中）
【外盘】KOSPI ±X% / 美股 / A50
【结论】买点/持有/规避 + 关键价位（支撑/压力/止损）
```

⚠ 诊股票/复盘禁止只给部分指标（如只给黄白线不给砖型/换手）——用户明确要求全套。
