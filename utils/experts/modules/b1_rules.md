# 图形买点体系B1战法（图形买点体系 · B1B2B3/S1S2S3）：量价 + J值 + 分时

## 一、核心波段框架：B1B2B3 三买三卖（图形买点体系骨架）
基于机构筹码思维，完整一轮行情分三买(B1/B2/B3)三卖(S1/S2/S3)。并非每只股票都走完全程，只有主线核心龙头走完全程；弱势股可能B1后直接下跌。看长做长，看短做短，级别要匹配。

### 三个买点
| 买点 | 定义 | 核心特征 | 操作定位 |
|---|---|---|---|
| B1 | 超跌首买 | J值打到大负值，股价阶段性超跌，空头动能充分释放 | 左侧抄底，试错建仓，盈亏比最高 |
| B2 | 突破确认 | 股价突破关键压力位（多空黄线/前高），量能配合 | 右侧加仓点，趋势确认后加码 |
| B3 | 加速主升 | 股价快速拉升，J值跟不上股价上涨速度（钝化） | 主升浪持有段，享受泡沫 |

### 三个卖点
| 卖点 | 定义 | 核心特征 | 操作定位 |
|---|---|---|---|
| S1 | 爆发冲顶 | J值到大正值并持续钝化，短期情绪极致亢奋 | 第一波减仓，锁定部分利润 |
| S2 | M顶构筑 | 股价二次冲高无力，形成双头形态 | 第二波减仓，大部兑现 |
| S3 | 顶背离出货 | 股价创新高但指标不创新高，主力托盘出货 | 清仓离场点，行情终结 |

## 二、B1战法（体系核心入门）
### 底层逻辑
B1 = 超跌后的第一类买点，本质是"顺大势、逆小势"——中期多头趋势内捕捉短期恐慌杀跌拐点。
核心原则：只买B1，绝不追高；买得低决定安全垫和盈亏比。

### 标准B1五大条件
1. 大趋势前提：股价站稳黄线，最好白线也在黄线上方
2. 超跌指标：J值 ≤ 13（勾到大负值）；-5以下=深度超跌更优（2026-08-10 与知识库对齐）
3. 量价结构：红肥绿瘦（上涨放量、下跌缩量），主力未出逃
4. 筹码结构：筹码峰集中，双峰填谷完成，换手充分
5. 动量确认：砖型图绿翻强红，短期动量由空转多

### B1两种形态
- 急跌型B1：连续快速杀跌，J值迅速砸到负值，V型反转，爆发力强容错低
- 缓跌型B1：阴跌磨底，缩量企稳，J值逐步走低，安全性高启动慢

### B1操作纪律
- 仓位：试错仓，总仓位10%~20%，不重仓
- 止损：B1最低点下方3%~5%，跌破无条件走
- 止盈：第一目标看黄线/前压力位，突破后转B2持有
- 大忌：不在主线的B1不做；白线在黄线下的B1降低预期

## B1止盈体系（2026-08-03 项目主理人确认补全：前高目标+盈亏比+次日开盘SOP）
### 盈亏比铁律（入场前必算，整套体系根基）
- 开仓前先划止损位 + 前高目标位，测算盈亏比 = (前高价-入场价) / (入场价-止损价)
- 只接受 **盈亏比 ≥ 2:1，最优 3:1**；达不到 2:1 直接放弃，不强行开仓
- 止损位：B1 信号低点下方（结构破位无条件离场）
- 逻辑：B1 是左侧埋伏、胜率中等，靠高盈亏比实现长期正向收益
- ⚠ 盈亏比优先于信号！哪怕完美 B1 形态，若止损空间大、上涨空间狭小，直接放弃

### 止盈第一目标 = 前高
- B1 第一止盈目标位：**前期高点（前高压力位）**
- 抵达前高出现滞涨/长上影/放量震荡 → 剩余仓位全部止盈
- 放量有效突破前高 → 继续持有，抬高止损博弈第二波行情
- 前高是第一目标不是唯一卖点：早盘极强、放量突破前高的允许放飞，不死板在前高无脑清仓

### 次日开盘执行（9:33/9:37 观察窗口）
- 适用：前一日尾盘 B1 入场，次日早盘短线决断
- **9:33/9:37 是观察窗口不是精确挂单点**——看资金持续性，机械卡点操作会踏空/卖飞
- 分支① 拉不起来（低开低走、反弹无力）→ **直接全部清仓拍掉，不格局**
  - 底层逻辑：砖型图多头信号隔夜失效，资金没有承接，预期破坏，不要扛单
- 分支② 顺利拉升（多头承接有力）→ **先卖 50% 底仓锁利**（消除浮盈回吐风险）
  - 剩余 50% 防守方案1（短线）：移动止损上移到成本线/今日开盘价，跌回全部离场
  - 剩余 50% 防守方案2（波段）：持有冲击前高第一目标位

### 环境微调
- 大盘弱势环境：放宽标准，拉升之后直接 70% 减仓，少放飞
- 主线热点行情：维持 50% 减仓规则，更多仓位博弈突破前高

### 硬性禁止
- **B1 被套之后向下加仓摊薄成本**（图形买点体系多次强调，绝对禁止）

### 灵活运用原则（不搞死板共振）
- 各信号独立触发、独立参考，叠加越多只代表胜率倾向更高，不是必要条件
- 大趋势（黄白线）是唯一硬性前提：白线<黄线时空头环境，所有买点信号降级为反弹
- B1 = J大负值（核心标尺）；红肥绿瘦、砖型翻红、单针下20 都是加分项
- 同样的信号，在主线板块里胜率翻倍，不在主线的少做

## 三、红肥绿瘦（量价健康度）
不是单根K线，而是3~5个交易日以上的波段量价结构：涨时放量、跌时缩量。

### 红肥（上涨段）
- 阳线实体饱满，影线短，收盘强势
- 阳线成交量较前一日放大30%以上
- 阳量总和显著大于阴量总和（14天阳量/阴量 > 1.65）
- 本质：主力主动吸筹承接

### 绿瘦（回调段）
- 阴线实体短小，多为小阴、十字星
- 回调成交量萎缩至前量50%以下
- 全程无量下跌，无放量砸盘
- 本质：主力压价洗盘并未出逃

### 用法
1. B1确认：B1前调整必须是绿瘦结构，放量下跌的B1是陷阱
2. B2验证：B1上涨后B2回调若缩量绿瘦，主力锁仓，B3概率大
3. 持仓健康度：主升持续红肥绿瘦可安心持有；出现红瘦绿肥（阳线缩量阴线放量）警惕见顶

## 四、J值（B1核心标尺）
J = 3K - 2D，可突破0~100区间。
### 超跌分级（2026-08-10 与知识库对齐：图形买点体系原话「KDJ勾13以下都算B1」）
- 基础B1：**J值 ≤ 13（勾到大负值）** → 不同时间周期下的阶段低点，日线/周线分别看
- 标准B1区间：J值 -5~-10，典型超跌买点
- 深度超跌：J值 -10以下，极端恐慌黄金坑概率大，但需警惕下跌中继
- ⚠ 核心标尺 = J 勾到 13 以下即触发 B1 前提；-5 以下属更深超跌（更优买点），不是必要条件

### 用法
- ✅ 大趋势多头 + 红肥绿瘦 + J大负值 + 砖型绿翻红 共振
- ❌ 下跌趋势中J值负值就抄底，往往抄在半山腰（J值持续钝化下跌）
- 对应卖点：J到大正值钝化（连续多日100以上走平）= S1冲顶卖点

## 五、分时战法（日内精细化）
### 高量比开盘战法
- 量比 > 1.5：增量资金进场，走强概率大
- 量比 2~5：黄金启动区间，配合站稳均价线可靠性极高
- 量比 < 0.5：存量博弈，放弃操作
- 开盘5分钟量比持续>1.5且股价在均价线上方 = 偏强可持股/低吸
- 开盘拉升但量比<1 = 无量诱多，冲高减仓
- 量比飙至5~10且高位放量滞涨 = 警惕出货

### 高开打黄线战法（分时均价线=当日多空生命线）
标准强势分时：小幅高开1%~3% → 回踩分时黄线不破 → 回踩缩量、二次拉升放量 → 黄线向上倾斜 = 日内最强承接，回踩低吸
弱势分时：高开跳水跌破均价线 → 反弹到黄线遇阻 → 黄线向下拐头 = 空头主导，任何反弹都是减仓点

### 分时做T规则
- 正T（先买后卖）：开盘5分钟站稳黄线+量比>1.5，回踩黄线低吸，冲高卖出
- 倒T（先卖后买）：开盘5分钟跌破黄线持续走低，反弹到黄线卖出，尾盘接回
- 铁律：分时黄线之上不做空，黄线之下不做多

## 六、执行流程（选股到卖出）
1. 海选标的：B1选股公式初筛 + 红肥绿瘦过滤，建观察池
2. 大趋势过滤：白线>黄线=强势多头优先；股价在黄线上白线在下=降仓；股价在黄线下=放弃
3. B1买点确认（四者共振）：J大负值 + 绿瘦结构 + 单针下20低位 + 砖型绿翻强红
4. 波段持有：B2突破加仓；连续4红砖减仓；红翻绿短线止盈；J大正值钝化(S1)大幅减仓
5. 终局离场：S2(M顶)或S3(顶背离)清仓离场，等下一轮B1

## 七、避坑总结
1. B1不是万能底：下跌趋势里的B1大多是下跌中继，必须大趋势过滤
2. J值负值不代表立刻涨：可以钝化再钝化，一定要等右侧动量确认（砖型翻红）
3. 红肥绿瘦看波段不看单日：单根放量阳线说明不了什么
4. 分时服从日线：日内分时再好看，日线空头也不重仓
5. 主线优先：同样形态在主线板块胜率翻倍，不在主线的B1少做
