# 全市场回测 `market_full_authority` 收益率算法审计报告

> 审计对象：`data/backtest/market_full_authority.md`（2026-09-12，区间 2024-01-01~2026-09-12）
> 审计标的：B2「平均单笔 +2.91%、胜率 41.9%、盈亏比 2.89%，但收益率 −18.9%」的自相矛盾
> 方法：只读审计；诊断脚本 `data/backtest/diag_return_algo.py`；检查点 `.ckpt_market_full_authority.pkl`
> 结论：**−18.9% 是算法（单账户"跳过重叠"+宇宙序 tie-break）产生的伪值，不是 B2 的真实收益，必须作废。**

---

## 一、算法定位（逐行引用）

报告的 `收益率% / 年化% / 最大回撤%` **并非**由 `utils/backtest.py:compound_curve`（351-383）计算。
驱动脚本 `utils/market_full_backtest.py:48` 导入的是 `utils.market_backtest` 的
`run_backtest_market / summarize / get_benchmark`，真实计算在 **`utils/market_backtest.py`**。

### 1.1 收益率/年化/最大回撤 —— `utils/market_backtest.py:244-275` `equity_curve()`

```python
244  def equity_curve(trades):
248      sorted_trades = sorted(trades, key=lambda x: x["日期"])   # 按信号日排序(稳定排序, 同日期保留原列表序)
249      capital = 1.0
250      free_date = None
...
255      for t in sorted_trades:
257          sig_date = datetime.strptime(t["日期"], "%Y-%m-%d")
260          hold = t.get("持有", 10)
261          if free_date is None or sig_date >= free_date:          # 仅当资金空闲(>=free_date)才复利
262              capital *= (1 + t["收益"] / 100)                     # 逐笔复利
263              free_date = sig_date + timedelta(days=hold + 3)     # 占用 hold+3 个日历日, 期间重叠信号全部跳过
264              done += 1
...
271      years = max((datetime.now() - datetime(2024, 1, 1)).days / 365.25, 1.0)  # 年化年数 ≈ 2.70
272      ret = (capital - 1) * 100                                   # 收益率%
273      annual = (capital ** (1 / years) - 1) * 100                  # 年化%
274      return {"收益率%": round(ret, 1), "年化%": round(annual, 1),
275              "最大回撤%": round(mdd, 1), "实际交易": done, "曲线": curve}
```

- **按时间轴逐日复利？否**——是「按信号日、单账户满仓、跳过重叠」的**逐笔非重叠复利**（落袋在每笔 exit 后统一折算，并非每日盯市）。
- **重叠交易如何合并？** 不合并——`free_date` 之后的同窗口信号**直接丢弃**（只保留窗口内第一笔）。
- **资金空闲期怎么处理？** 空闲期 capital 不变（不计息、不空仓收益），仅等待 `free_date`。
- **成本怎么扣？** 不在 `equity_curve` 扣；已在 `utils/backtest.py:323` `pnl=(exit-buy)/buy - TRADE_COST` 中扣净，TRADE_COST=0.072%（backtest.py:45）。
- **年化年数** `years≈2.70`（(today−2024-01-01)/365.25）。

## 二、三算法复算对比表（B2 为主，五战法并列）

| 战法 | 交易数 | 报告收益率% | (a)全部逐笔顺序复利 | (b)报告原算法(精确复刻) | (b)实际交易数 | (c)逐日净值分散复利 |
|---|---:|---:|---:|---:|---:|---:|
| B1 | 102374 | 188.5 | 1.65e+76 % | **188.5** | 129 | 317.7 % |
| **B2** | **1261** | **−18.9** | **7.58e+13 %** | **−18.9** ✅ | **76** | **18.0 %** |
| B3 | 275 | 90.9 | 267.6 % | **90.9** | 85 | 182.1 % |
| 砖型 | 219354 | 48.5 | 4.09e+123 % | **48.5** | 124 | 429.7 % |
| 单针 | 4123 | −35.8 | 9.52e+09 % | **−35.8** | 124 | −5.8 % |

- **(a)** 全部 1261 笔按日期顺序连乘：B2 = **+7.58×10¹³ %**（天文数字，正）。
- **(b)** 精确复刻 `equity_curve`：B2 = **−18.9 %**，与报告**完全一致**（五战法全部对得上，证明复刻忠实）。
- **(c)** 全部交易收益沿持有期摊到日历日、同日多笔取日收益均值（分散化每日盯市）：B2 = **+18.0 %**（正）。
- **结论：只有 (b) 这一种（即报告自身的缺陷算法）能给出 −18.9%；任何合理复算都是正的大数。**

## 三、为什么 (b) 会得到 −18.9%：被复利的"子集"严重偏差

| 战法 | 被复利笔数 | 选中子集平均单笔% | 全集平均单笔% | 偏差 |
|---|---:|---:|---:|---:|
| B1 | 129 | +1.109 % | +0.270 % | **+0.839pp（虚高）** |
| **B2** | **76** | **+0.336 %** | **+2.910 %** | **−2.574pp（严重低估）** |
| B3 | 85 | +0.798 % | +0.490 % | +0.308pp |
| 砖型 | 124 | +0.417 % | +0.310 % | +0.107pp |
| 单针 | 124 | −0.224 % | +0.540 % | **−0.764pp（负偏）** |

B2 全 1261 笔平均 **+2.91%/笔**（胜率 41.9%、盈亏比 2.89，明确盈利），但被实际复利的 76 笔平均仅 **+0.336%/笔**。
也就是说，(b) 恰好挑中了"运气最差"的一小撮交易来连乘，结果自然被拉到 −18.9%。

## 四、决定性证据：秩稳定性测试（同算法，仅打乱输入顺序）

`equity_curve` 用稳定排序，同日期多笔信号"谁排第一"由输入列表序（= 宇宙股票排序）决定。
我们**保持算法不变，仅 `random.shuffle` 输入列表**（只改变同日期 tie-break），跑 30 次：

| 战法 | 原始% | 最小% | 最大% | 摆动幅度 |
|---|---:|---:|---:|---:|
| B1 | 188.5 | −30.8 | 365.6 | 396.3pp |
| **B2** | **−18.9** | **−64.9** | **+421.8** | **486.7pp** |
| B3 | 90.9 | 68.9 | 115.9 | 47.0pp |
| 砖型 | 48.5 | −58.2 | 278.4 | 336.6pp |
| 单针 | −35.8 | −69.6 | 134.5 | 204.1pp |

> **B2 在乱序下从 −64.9% 摆到 +421.8%**。一个真实策略的收益率不可能由"列表怎么排序"决定。
> 这确证 −18.9% 是方法缺陷（极小任意子集 + 单账户跳过重叠）的产物，不是 B2 的经济属性。

## 五、连带影响（主理人能不能引用这些数字）

同一缺陷贯穿全部五战法，方向**双向失真**：

- **B1 +188.5% / B3 +90.9%**：符号正确（确实正），但**幅度被同一"极小任意子集"高估且极不稳定**（B1 乱序后 −30.8%~+365.6%；选中子集比全集幸运 1.8 倍）。**不能直接引用作"收益率"。**
- **B2 −18.9% / 单针 −35.8%**：**错号伪值**。真实经济性：B2 明确为正（全量 +7.6e13%、分散 +18%）；单针在分散净值下约 **−6%**（近零偏弱），绝非 −35.8%。
- **可依赖的口径**：`胜率 / 盈亏比 / 平均单笔%`（基于全部交易）是真实的；`收益率% / 年化% / 最大回撤%`（基于 76~129 笔任意子集）全部不可引用。

---

## 六、结论（确证）

1. **−18.9% 由 `utils/market_backtest.equity_curve`（market_backtest.py:244-275）算出，已精确复刻（(b)=−18.9%，与报告一致）；但它不是 B2 的真实收益。**
2. 收益率只复利了 **76/1261** 笔，且这 76 笔平均仅 **+0.336%/笔**，远低于全集 **+2.910%/笔**（偏差 −2.57pp）——被复利的恰好是运气最差的子集。
3. **决定性证据**：同算法仅打乱输入顺序，B2 在 **−64.9% ~ +421.8%** 间剧烈摆动（486pp）。真实策略收益不可能由列表乱序决定。
4. 因此 **−18.9% 必须作废，不可引用**。B2 真实经济性明确为正：全量顺序复利 +7.6×10¹³%、逐日分散 +18.0%。
5. **连带**：同一缺陷影响全部五战法。B1 +188.5%、B3 +90.9% 符号正确但幅度被同一极小任意子集高估且不稳（B1 乱序 −30.8%~+365.6%）；B2 −18.9%、单针 −35.8% 为错号伪值（单针真实约 −6%、B2 真实约 +18%~+107%）。**五个收益率% 无一可引用；胜率/盈亏比/平均单笔%（基于全部交易）可靠。**
