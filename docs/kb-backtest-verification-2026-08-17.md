## 三、核心结论

1. **B2 在知识库定位 = "B1之后的确定性买点，波段启动关键信号"** → 胜率理应最高。
   代码已按"B1之后"前置修正，但样本变少（18笔），说明纯机械信号难完全复现"确定性"。

2. **买入后期待 ≠ 硬止损**：B1"3日恢复上涨"、B2"2日大幅拉升"是期待，不是无条件离场信号。
   → 代码已删除"3日/2日确认失败离场"硬规则，回归纯止损+止盈+破白线。

3. **止损本质 = 结构位**：B1=买入K线最低点（3-5价位容差）；B2=N型前低（≈买入当日K线最低点）；
   B3=突破大阳线中间位置。三者都是"破位走人"，不是固定百分比。

4. **胜率低的根源**：机械回测无法复现 图形买点体系的人工叠加过滤
   （主线/题材、红肥绿瘦、换手率、量比、筹码），432个B1信号里大量非主线票，
   实际使用者靠"审美"过滤后胜率显著提升。这是回测的固有局限。
