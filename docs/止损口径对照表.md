# 图形买点体系 · 止损口径对照表

> **文档定位**：本项目 图形买点体系(图形买点体系 v1.0 / pattern 课件)所有「止损/离场/形态阈值」口径的**唯一权威对照**。
> **边界声明**：本表**只覆盖 图形买点体系**。方向仓位体系(三不原则、认知变现、总仓位≤50%、五日线战法 -20%)是另一套独立体系，**不在本表范围**，其参数亦不在 `utils/strategy_config.py` 中。
>
> **代码唯一参数源**：`utils/strategy_config.py` → `CONFIG`。除该文件外，任何模块不得再硬编码以下数值。
>
> 最后更新：2026-09-10（T01 配置中枢落地）

| 冲突项 | 归一前（散落/矛盾） | 归一定案 | 处理 |

| 砖型强红阈值 | `brick.py:132/246` 硬编码 `0.75`(3/4) vs `screen_brick_xg.py:81` 硬编码 `2/3` —— **同一体系两套打架口径** | 三者统一改读 `CONFIG.BRICK_RATIO`（=2/3，用户裁决「一套逻辑，都是2/3最好」） | ✅ **行为变更**（见下注） |

> **⚠️ T01c 两处行为变更的影响量化（2026-09-10 实测，commit `89771a0`）**：
> - **砖型 3/4 → 2/3**：用真实缓存数据（64 只 / 50,976 次判定）对照，两口径判定结果为 **0 处差异**。
>   原因：`brick.py` 的判定链是 `cur < 绿峰×0.5` → `cur >= 绿峰` → `cur >= 绿峰×ratio`，
>   前两个分支已覆盖绝大多数取值区间，落在 `[2/3, 3/4)` 这个夹缝里的样本几乎不存在。
>   → 结论：**统一口径是工程正确性收益（消除同体系打架），对该样本集无实际信号影响**。
> - **单针 80 → 85**：超买预警门槛抬高，判定**更宽松**（原先 s∈(80,85] 会报超买，现在不报）。
>   这是用户明确裁决的口径对齐（知识库《知行深V.txt》原文为 85），非优化调整。

> **说明**：仓库中仍有 `utils/battle.py:136`(`ll20 * 0.97` 信号低点止损参考)、`utils/b1_full.py`(`0.97` 对子底破位)、`utils/brick_carry.py`(`0.97` 箱体上沿)等 `0.97` 数值。经核实这些是**形态/结构判定阈值，与止损口径无关**，不在本次归一范围，按最小变更原则**未改动**。
