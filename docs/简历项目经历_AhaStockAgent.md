## §1 简历条目 · 主版(AI 应用 / LLM 应用方向,可直接粘贴)

### AhaStock Agent · A 股智能交易 Agent(个人全栈项目)
**2026.08 – 至今 | GitHub: https://github.com/Ahao0911/ahao-stock-agent**

以 LLM Agent 为核心的智能交易决策系统:将两套专业交易体系(10 个战法模块)完整工程化为可执行代码,按「规划 → 工具执行 → 结果反馈 → 复盘修正」的 Agent 闭环,由 Agent 运行时驱动每日盘前/午间/盘后自动运行,无人值守。

**技术栈:** Python · Pandas/NumPy · 多源行情数据爬取与路由 · 时序预测 · 回测框架 · LLM Agent / Tool-use 架构 · Skill 技能编排 · HTTP API · JSON/CSV · Git

- **Agentic 交易闭环**:构建盘前研判(三情景概率加权 45/35/20)→ 盘中代码选股 + 午间印证 → 自动止损/止盈执行 → 盘后六维复盘 → 认知回写的完整决策循环;接入交易日历自动识别节假日,系统已连续 **20+ 个交易日无人值守稳定运行**。
- **工具层 + 技能层工程化**:自研 **45+ 个 Python 工具函数**(数据/技术指标/选股/风控/日志)作为 Agent 可调用能力层;将 7 大交易场景封装为**可插拔 Skill**(盘前提示/盘中选股/个股分析/交易记录/盘后复盘/专家会诊/图形买点体系),支持按需装载与组合调用,并内建 2 位人物专家 + 10 战法模块的专家系统。
- **多源数据路由与容错**:自研统一数据网关,四级优先级路由 5 类数据源(a-stock-data 47 端点 / 非凸 ftshare 153 接口 / 妙想 MX / 腾讯·akshare·mootdx·iFinD),断源自动降级、限流防封、本地缓存,实现 1000 只股票日 K 并发拉取 **8 分钟全量覆盖**。
- **量化回测验证体系**:自建回测框架(满仓轮动复利口径,含胜率/盈亏比/年化/最大回撤),对 5 套候选战法在 1000 只股票、2024.01–2026.08 样本上完成 **8.2 万笔信号级回测**,与沪深300 同期(+40%)基准对照,量化甄别 3 套正期望策略(B1/砖型/B2,年化 12.3%–18.5%、盈亏比 2.3–3.7)并剔除 2 套负期望策略。
- **资金面时序预测 + 模拟盘验证**:基于活跃市值指标构建自回归(AR2)预测模型,滚动 1500 日窗口自动重拟合,经无未来函数逐日回验 **MAPE ≈ 1.2%**;100 万模拟盘按真实交易规则自动运行,自动止损纪律 **9/9 全部规则化执行**。

## §2 后端开发方向的微调要点

投后端岗时,把上版第 1、5 条压缩,强化以下工程点(可直接替换对应 bullet):

- 用 Python 标准库 `http.server` 自研数据桥服务(端口 8899,线程化并发),暴露 8 类 JSON API(快照/实时报价/K线+指标/模拟盘/交易日志/新闻情绪/复盘报告/健康检查),兼容 numpy 类型序列化、NaN 安全处理,不依赖任何 Web 框架。
- 自研多源数据网关:优先级路由 + 断源自动降级 + 请求限速防封 + 磁盘缓存,保证数据链路高可用(1000 只股票并发拉取 8 分钟完成)。
- 数据落盘统一 JSON/CSV 结构化存储(行情快照/交易流水/复盘报告按日归档),无数据库依赖,天然可审计、可回溯。
- 自动化调度与交易日历引擎:盘前/午间/盘后三时段触发 + 节假日自动跳过,全程无人值守可观测(每步留痕)。

**标签建议换为:** Python · 多线程 · HTTP 服务 · 爬虫与反爬 · 数据管道 · 定时任务 · JSON/CSV 存储 · Git

## §3 怎么体现 "Agent loop / Harness 思想"(关键)

你没自研 loop/harness(真实代码里没有,也别写),但**完全可以在简历里体现思想层**。推荐措辞(按诚实度与效果排序):

**A. 架构分工式(最推荐,面试不怕追问)**
> "系统构建在通用 Agent 运行时之上,由宿主提供 ReAct 循环与工具调用编排;**本人负责全部领域工程** —— 将交易规则代码化为 45+ 工具与 7 个可插拔技能,设计闭环工作流,使 Agent 在无人值守下自主完成选股、风控与复盘。"

**B. 工作流式(最安全,纯事实)**
> "以 Agentic Workflow(规划 → 执行 → 反馈 → 复盘修正)组织每日交易决策流水线;决策规则全部代码化,杜绝自然语言主观判断。"

**C. 前沿范式式(最醒目,略需铺垫)**
> "参考 Tool-use / Skill-based Agent 最新范式设计系统:LLM 负责理解与决策,45+ 工具函数负责执行,7 个可插拔技能负责领域知识装载,二者通过宿主 Agent 运行时解耦。"

> 简历正文放一句话即可(建议 A 或 B),C 的词汇("Tool-use / Skill-based")放到**技术栈标签行**,不占正文。

## §4 红线:这些词不要写(会被追问穿帮)

| 不要写 | 为什么 |
|---|---|
| "自研 Agent 框架 / 自建 ReAct 循环" | 代码里没有,深挖即穿帮 |
| "基于 LangGraph / AutoGen 开发" | 实际未使用,且面官很熟,一问就露 |
| "实现 Agent Loop / 实现 Harness" | 同上 |
| "模型微调 / RAG" | 未做,别蹭不相关的热点 |

**统一口径(被问"loop 是谁实现的"时):**
"项目的 Agent 运行时复用通用宿主平台(类似 Claude Code / 扣子的运行时),ReAct 循环、工具调用、沙箱权限由平台承载;我的核心工作在领域层 —— 把交易体系变成 Agent 能可靠调用的工具与技能,并设计驱动它每天正确决策的闭环流程。类比:我负责 Agent 的'大脑内容'和'手脚',平台提供'神经回路'。" —— 这套说辞既诚实,又展示架构分层认知,面试反而是加分点。
