## 二、v2（2026-09-12 起启用）

**只改 3 条，其余完全沿用 v1。**

| # | 变更 | 数据依据（全市场 4,935 只回测） |
|---|---|---|
| **1** | **B3 中继 = 固定持有 10 个交易日** | 用户敲定（`CONFIG.HOLD_DAYS_BY_STRAT["B3"]=10`） |
| **2** | **B2 不再作独立买入信号**，只作 **B1 的加仓位** | B2 独立口径最弱：交易胜率仅 **31.5%**；而作为加仓位有效 |
| **3** | **加仓 = 半仓追加**（B1 建仓额 × 50%），**跟随主仓离场**；**不设**"仅盈利后加仓" | 全量 **3,737 笔**加仓腿 **+1.604%/笔**（胜率 52.8%）；加仓后整笔 **+4.279%** vs 不加仓 **+3.798%**（**增利 +0.481pp**）；另配 B2 自己的短周期规则反而**最差**（+0.993%，中位 −4.68%）；"仅盈利后加仓"天然 **100% 满足**（加仓时 B1 腿浮盈中位 **+9.57%**），故该条件无约束力 |

**⚠️ 已知代价（写在这里以免遗忘）**：加仓把整笔**胜率从 82.5% 拉到 63.8%**，期望小增、波动变大 →
**必须配合既有单票敞口上限**（组预算×1.5 或 总资产×15%，取 min），不得因"加仓有效"而放宽敞口。

### 不变的部分（v2 完全沿用 v1）
止损三档（−4% 盘中 / −3% 收盘 / −2% T1）· 单只 50% 组预算 · 单组最多 2 只 · 单票敞口上限 ·
全抡让渡 · 三轮买入 · 无限期运行。

## 三、版本切换与回滚

```bash
# 查看 v1 基线
git show v1-sim --stat

# 方式1：只回滚单个文件到 v1
git checkout v1-sim -- utils/strategy_config.py

# 方式2：整体切到 v1 状态做对照（不改动当前分支）
git switch -c v1-rollback v1-sim

# 方式3：代码内开关（不切 git 即可回 v1 行为）
#   utils/strategy_config.py → CONFIG.SIM_RULES_VERSION = 1
```

**代码内开关**：`CONFIG.SIM_RULES_VERSION` 默认为 `2`；置 `1` 时恢复 v1 行为
（B2 可独立买入、加仓无差别加倍），无需动 git。
